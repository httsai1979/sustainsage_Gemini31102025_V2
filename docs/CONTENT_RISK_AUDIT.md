# 內容風險稽核

## 已清除

- 虛構或不應公開的人物、team 與 Partner 類角色。
- 未經核准的資格、認證與方法論聲明。
- 未驗證 testimonials、客戶結果與看似真實的合成案例。
- 多套互相衝突的服務方案與價格。
- `sustainsage.com` 舊網域與舊聯絡信箱。
- 不應公開的電話、人物私生活與家庭關係來源。
- Early-career、graduate、製造顧問、AI／數位轉型顧問等本版排除定位。

## 自動防線

`npm run check:risk` 掃描 pages、components、content、lib 與 public，攔截：

- 指定人物與虛構角色；
- 大寫資格縮寫與未核准認證說法；
- 舊網域與舊信箱；
- 未核准公開價格。

掃描刻意區分大寫資格縮寫與工具 JavaScript 常用的小寫累加器變數 `acc`，避免誤判正常程式碼。

## 仍需人工把關

自動掃描無法判斷所有暗示性文案。新增內容仍需確認：

- 是否暗示就業、升遷、收入或心理狀態保證；
- illustrative scenario 是否被誤寫成真實客戶案例；
- 是否新增未取得的資格或第三方背書；
- 是否讓四種情境重新變成四項產品。
